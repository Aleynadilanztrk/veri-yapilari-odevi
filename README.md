Veri Yapıları Projesi – README

Bu proje, BMB 212 Veri Yapıları dersi kapsamında Stack, Queue ve Binary Search Tree (BST) veri yapılarının Java dilinde, hazır kütüphane sınıfları kullanılmadan sıfırdan implement edilmesi amacıyla geliştirilmiştir.

Projenin Amacı

Veri yapılarının temel çalışma mantığını anlamak ve farklı problem türleri için uygun veri yapısını seçip uygulayabilme becerisi kazanmaktır.

Kullanılan Veri Yapıları
-Stack (Yığın):
-Dizi tabanlı ve bağlı liste tabanlı implementasyon yapılmıştır.
-Cümle ters çevirme ve parantez/simge eşleşme problemleri çözülmüştür.
-LIFO (Last In First Out) mantığı kullanılmıştır.

Queue (Kuyruk):
-Bağlı liste tabanlı kuyruk yapısı oluşturulmuştur.
-Yazıcı simülasyonu ve palindrom kontrolü problemleri uygulanmıştır.
-FIFO (First In First Out) mantığı kullanılmıştır.

Binary Search Tree (BST):
-Ekleme, silme ve arama işlemleri implement edilmiştir.
-Inorder, preorder ve postorder traversal yazılmıştır.
-Kelime sayma ve en sık geçen kelime bulma uygulaması yapılmıştır.

Teknik Gereksinimler:
-Java programlama dili kullanılmıştır.
-Java’nın hazır Stack, Queue ve LinkedList sınıfları kullanılmamıştır.
-Tüm veri yapıları manuel olarak implement edilmiştir.
-Big-O karmaşıklıkları gerekli yerlerde belirtilmiştir.
-main() metodu içinde birden fazla test senaryosu çalıştırılmıştır.

Sonuç:
Bu proje kapsamında Stack, Queue ve BST veri yapılarının temel çalışma prensipleri, kullanım alanları ve problem çözme süreçlerindeki rolleri anlaşılmıştır.
